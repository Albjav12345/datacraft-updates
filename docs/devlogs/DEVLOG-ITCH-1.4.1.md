# DataCraft 1.4.1 — A clearer, aligned Table

DataCraft 1.4.1 refines the Table workflow introduced in 1.4.0. This update focuses on a more consistent grid, clearer navigation and updated guidance, while keeping your existing data formats and authoring workflow compatible.

## A cleaner table grid

- Instance names and typed inputs share the same vertical alignment, with headers positioned over their corresponding columns.
- Uniform row backgrounds and subtle column dividers give the table a more consistent appearance.
- Values, Set value controls and validation messages stay grouped within their corresponding cells.

## Clearer column and page navigation

- Choose visible field groups by name through Columns, beside Order, instead of using a separate row of field-navigation arrows.
- Previous/Next buttons match Cards, with a labelled counter for instance pages. Bulk-review pages use the same button style.
- Field selection and instance pagination remain separate, making it clearer whether you are changing the visible columns or moving through your instances.

## Updated Help and authoring guidance

The offline Help and illustrated authoring guide now reflect the refined Table layout, including the Columns selector and the page controls.

Selections, validation, reviewed bulk changes and native Undo/Redo retain their existing behavior. Updating drafts and publishing the game's generated catalog remain separate actions.

## Updating from 1.4.0

Existing templates, stable IDs, generated models and save/catalog formats remain supported. The itch.io edition retains its official account and update workflow. Back up your project before updating.
