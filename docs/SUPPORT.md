For questions, bugs and feedback, use this address or **Help → Contact support** in Unity. The button opens your email app; nothing is sent automatically. The address is selectable/copyable in Help.

## Before reporting a problem

Check [Troubleshooting](guides/Troubleshooting.md) and the guide for the affected workflow. For installation, read [Installation](INSTALLATION.md); for store/account issues, read [Updates](guides/Updates.md).

## Include enough to reproduce

- **Settings → Copy version details**: installed DataCraft version/source and Unity version.
- The page/operation, expected result and actual result.
- Minimal reproduction steps and the first relevant Console error/message.
- A screenshot when layout or wording matters; a small disposable reproduction project when useful.
- For builds: platform, backend, renderer and stripping level.
- For updates: retail edition, last successful check, metadata issue date and visible verification/account/download phase.

Do not send passwords, API keys, authentication headers, OAuth tokens/codes, download keys, private signing keys or production player saves. Avoid unnecessary personal/project paths in screenshots.

Support does not include a response-time SLA or a guarantee of external API availability. [Compatibility](guides/Compatibility.md) distinguishes declared requirements from tested configurations. [Changelog](CHANGELOG.md) describes releases; your store controls actual download availability.
